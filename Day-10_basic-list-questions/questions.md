# 🏫 Class Questions (7 Problems)

### 1️⃣ Find the Maximum and Minimum Element

* **Input:** `[10, 25, 3, 18]`
* **Output:** `Max = 25`, `Min = 3`

---

### 2️⃣ Reverse a List (Manual Method Only)

* **Input:** `[1, 2, 3, 4, 5]`
* **Output:** `[5, 4, 3, 2, 1]`

  ✨ Two pointer technique, no `list.reverse()` and no `[::-1]`.

---

### 3️⃣ Check if a List is Sorted (Ascending)

* **Input:** `[1, 2, 3, 4, 5]`
* **Output:** `Sorted`

---

### 4️⃣ Remove All Duplicates From a List (Preserve Order, No `set()`)

* **Input:** `[1, 2, 2, 3, 3, 4]`
* **Output:** `[1, 2, 3, 4]`

---

### 5️⃣ Merge Two Lists Without Using `+`, `extend` or Unpacking

* **Input:** `[1, 2, 3]` and `[4, 5]`
* **Output:** `[1, 2, 3, 4, 5]`

# 🏠 Homework Questions (7 Problems)

### 1️⃣ Find the Second Largest Element

* **Input:** `[10, 20, 4, 45, 99]`
* **Output:** `45`

---

### 2️⃣ Rotate a List to the Right by K Steps

* **Input:** `[1, 2, 3, 4, 5]`, `K = 2`
* **Output:** `[4, 5, 1, 2, 3]`

---

### 3️⃣ Check if Two Lists Are Equal (Same Order)

* **Input:** `[1, 2, 3]` vs `[1, 2, 3]`
* **Output:** `Equal`

---

### 4️⃣ Count Even and Odd Numbers in a List

* **Input:** `[2, 5, 7, 8, 10]`
* **Output:** `Even = 3`, `Odd = 2`

---

### 5️⃣ Find All Unique Pairs Whose Sum Equals a Target

* **Input:** `[1, 2, 3, 4, 5]`, target = 6
* **Output:** `(1,5), (2,4)`

---

### 6️⃣ Left Shift a List by One Position

* **Input:** `[1, 2, 3, 4]`
* **Output:** `[2, 3, 4, 1]`
  ✨ Manual shifting, moving first element to end.

---

### 7️⃣ Count How Many Times an Element Appears in a List

* **Input:** list = `[1, 4, 4, 4, 2]`, element = `4`
* **Output:** `3`
